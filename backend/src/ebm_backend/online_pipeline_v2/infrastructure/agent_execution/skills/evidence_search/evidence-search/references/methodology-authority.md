# Methodology Authority

The Protocol is authoritative for the review's approved scope, sources,
restrictions, and named methodology choices. It may leave execution details
open and may contain no source-specific strategy.

Identify, retrieve, and inspect the current, directly applicable official or
primary authority needed to interpret those choices and to develop each
source-specific strategy. Also inspect the named source's current vocabulary,
syntax, interface, and export guidance. Record the authority and version used
in the Search Run narrative or a task issue.

Do not treat this Skill, repository history, a benchmark convention, or model
memory as the source of an external standard's substantive rules. If current
authority materially conflicts with the Protocol, preserve the Protocol,
report the conflict, and do not silently replace the approved method. When the
Protocol leaves an execution choice open, resolve it professionally from the
consulted authority and record the choice and rationale.

Evidence Search ends with source-level Search Runs and bibliographic Records.
Duplicate identification, screening, Report collation, Study identity, and
eligibility decisions belong to Study Selection. Supplementary searching that
requires included Reports is requested from that downstream boundary and is
not automatically executed by the current task.
