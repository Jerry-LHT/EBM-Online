# Professional Workflow

Use the current Cochrane Handbook Chapter 5, *Collecting data*, as the directly
applicable official starting authority when the Protocol describes a Cochrane
intervention review:
https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05

Do not treat this reference as a frozen copy of the standard. Inspect the
current authority during the run and follow the Protocol where it constrains
review-specific choices.

Apply the stable collection method:

- use the Study, not a Report, as the extraction unit;
- use a structured, Protocol-linked collection form;
- collect source-faithful data before subsequent transformation;
- collect methods, participants, setting, interventions, outcomes, results,
  funding, conflicts, provenance, and missingness needed by this review;
- characterize an outcome by domain/title, measurement or definition, metric,
  aggregation, and timing;
- collect result-specific denominators and the most detailed useful numerical
  data available;
- collate multiple Reports without discarding discrepancies;
- retain original values, calculated values, and the calculation used;
- compare the magnitude and direction of transformed data with the Report.

For each requested field or Result, first record the scope of the source that
was actually read, then make the separate professional judgement whether that
source reports the item. These judgements must not be collapsed: an inspected
Report may have an unreported item, while an inaccessible Report leaves the
item unavailable rather than unreported. Preserve reported prose and
categories as source data even when no numeric transformation is appropriate.

Characteristics and Results are different data categories within one Data
Collection task. They share Study, Report, arm, outcome, and evidence identity,
but retain distinct fields and quality considerations. Do not run a global
Characteristics task followed by an unrelated Results task. Collect both while
reading each Study's linked Reports, then transform source Results in a later
step.

The Protocol may require other directly applicable authorities for a study
design, outcome form, or statistical conversion. Locate and inspect those
authorities rather than embedding their substantive rules here.
