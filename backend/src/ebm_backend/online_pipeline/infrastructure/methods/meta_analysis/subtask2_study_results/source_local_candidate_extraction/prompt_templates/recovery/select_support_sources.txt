Task
For one article-local candidate with open evidence needs, choose which unread
article sources should be read next to help resolve those needs.

Stage responsibility
- Use the article-local candidate setting, current open needs, current
  materials context, and source profiles.
- Select sources that are plausibly useful for resolving the listed needs for
  this candidate setting.
- Treat the current candidate setting as the scope of the recovery task. A
  selected source should plausibly help complete this candidate, not merely the
  broader review or workflow topic.
- First use data type compatibility: prefer sources whose data packages contain
  value types that match the open need.
- Then use meaning compatibility: prefer sources whose data-package meaning
  descriptions are semantically compatible with the candidate setting and the
  missing field context.
- Prefer recall over over-pruning when a source profile may contain compatible
  denominators, percentages, event counts, arm labels, outcome wording, or
  timepoint clues.
- Do not select sources already read for this candidate.
- Do not extract materials.
- Do not calculate.

Decision boundary
- Select a source if its profile suggests it may contribute evidence relevant
  to at least one open need for this candidate's article-local setting.
- Before selecting a source, check whether its profile contains a data package
  whose meaning, scope, or support role is compatible with the current
  candidate setting.
- Do not require exact wording overlap.
- A source may be useful even if it does not contain a candidate result row,
  for example when one of its data packages appears to contain usable totals,
  counts, percentages, or clarifying denominator/result context.
- A source may be selected even when it does not contain the same result row,
  but only if it may provide candidate-compatible support material such as arm
  totals, denominator basis, sample frame, arm mapping, percentage basis, or
  uncertainty basis.
- Do not reject a source only because it is a characteristics/source-context
  table if one of its data packages appears semantically useful.
- Do not select a source only because it matches the broader review/workflow
  topic. It must plausibly help complete the current candidate.
- Do not select a source when the available profile points to a different
  article-local setting and does not explain or support the current candidate.
- Respect the source-profile descriptions as source-grounded package summaries.
  Do not assume a package means more than its description supports.

Return only JSON:

  "selected_source_ids": [],
  "warnings": []
}
