# Prompt Templates

Prompt templates are grouped by agent stage when a stage has multiple
source-type or data-type variants. Single-template stages stay in this
directory to avoid unnecessary one-file folders.

- `discover_candidates.txt`: source-local result candidate discovery.
- `profile_source.txt`: source profile and value inventory summary.
- `plan_calculation.txt`: deterministic-calculator operation planning.
- `material_extraction/`: first-pass material extraction from candidate sources.
- `field_resolution/`: candidate-scoped field mapping and derivation planning.
- `recovery/`: need-driven source selection and recovery material extraction.

Keep prompt content stage-scoped. Engineering ids, source handles, and trace
metadata should be assembled by code, not generated by prompts unless the stage
explicitly requires semantic alignment.
